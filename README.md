# Mazda Login Form

A modern and responsive login and registration page inspired by Mazda's design.

## Features
- Login and registration forms
- Email and password input fields
- Password confirmation during registration
- Social login buttons for Google, Apple, and Facebook
- Responsive and clean user interface
- Custom styling with HTML and CSS

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Getting Started
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## Note
This project is a front-end demonstration. Real user authentication and account registration require a backend or authentication service.
